Sobre o projeto

Este projeto apresenta uma análise de dados climáticos de diferentes regiões e cidades brasileiras no período de 2015 a 2024.

A análise considera informações como temperatura, volume de chuva, umidade, velocidade do vento, eventos extremos e níveis de alerta.

O objetivo é observar como as condições climáticas variam ao longo do tempo e entre diferentes localidades, permitindo comparar os dados e identificar os principais padrões encontrados.

O projeto reúne análise, visualização de dados e um dashboard interativo para apresentar as informações de forma clara e fácil de explorar.

Tecnologias utilizadas

As seguintes tecnologias e bibliotecas foram utilizadas para preparar, analisar e apresentar os dados:

Dashboard interativo

O dashboard foi desenvolvido com Streamlit para reunir as principais informações da análise em uma interface simples e interativa.

É possível filtrar os dados por ano, região e nível de alerta. Ao alterar os filtros, os indicadores, tabelas e gráficos são atualizados para representar apenas os dados selecionados.
